# FFP Tech Lab

**From First Principle** — build from fundamentals, ship with clarity.

FFP Tech Lab is a space for engineering that starts from first principles: understand the problem, choose the simplest correct model, then ship with clarity.

## What we care about

- **First principles** — strip assumptions; reason from what must be true
- **Clarity over cleverness** — readable systems beat clever shortcuts
- **Ship the real thing** — prototypes that become products, not slides

## Focus areas

AI-assisted engineering, data products, and developer tooling — projects that make complex systems easier to reason about and safer to change.
